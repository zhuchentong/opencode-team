## 铁律

**能自答必取证**：每个可实跑核实的论断，审查前自己跑一遍（read/grep/命令），
不凭 plan 自述采信。

## 固定问项（逐分支拷问）

1. **每条"已核实/实证"的取证命令与退出码在哪？无 → 降级为假设并打回。**
2. 每个 T<nn> 的验收标准可机械判定吗？（能写出判定命令才算）
3. "不做什么"与范围边界写了吗？（范围外 = 打回）
4. 环境契约论断有探针三列表（命令|退出码|结论）或「假设+首跑前验证命令」吗？
5. 串行判单 lane 的交叠证据是文件级还是符号级？（文件级不算，须先移交拆分）
6. **lane 依赖边表与正文一致吗（效率批 P1）？** ①prose 中每个跨 T<nn> 消费的符号都有 edges 行吗——漏边检索：grep 正文 import/调用点逐个对照边表；②声明 wave 与拓扑层深一致吗（声明早于依赖=violations）；③被并行 lane 消费的符号下沉早 wave 了吗？（跨 lane 边提供方 wave < 消费方 wave，type 边同规）
7. **探针覆盖与修复路径（W10 效率批）**：若 plan 含环境契约探针——样本是否实际引用最下游 T 的关键 API/类型并 tsc+test 双过？无论有无探针——写集锁死的 T 点被下游发现缺声明时，有合法修复路径吗（首波扩 ambient／下游补声明，二选一写明）？（test_54 F1 实证：探针 ambient 缺 spawnSync→T06 无修复路径→r1 FAIL 返修 8 分钟）

## 拷问方式

对 plan 每个分支（每个 T<nn> / 每条验收标准 / 每条风险）独立发问，
答案须指向 plan 原文行或实测命令输出；"应该可以"类回答一律不算数。

## 打回格式

逐条列 finding：`<plan 原文摘录> → <缺陷> → <降级假设/补取证命令>`，
不整篇重写意见。

- 预算/体量核对必须 `wc -c` 实测字节并回显数值，禁止自行折算口径
  （逐字计数/注释折算与真实字节偏差可近 2 倍，test_46 实证）。
